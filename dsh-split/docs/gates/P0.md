## 3. 放行结论与遗留项

1. **F12 改为设计约束**：宿主任由两份可编辑根并存，工作台必须在任何时刻对每个会话只呈现一次。
2. **`maximizeGroup` 未决**：真机抛 `Cannot read properties of undefined (reading 'parentElement')`。"临时放大"要么换公开路径，要么列为风险并给降级方案（不阻断其余工作）。
3. **P-2 的"同时可见"缺少运行时数据**：本次侧栏处于收起态；补丁完成后用同一探针复测（动作 5，先把侧栏展开）。
4. 补丁按 **M-A1** 交付，生效需用户自己重启一次。

- 两套 Sidebar 同时可见的真实表现。
