# 紧凑连接界面

版本：`0.1.0-phase1.4`。开发分支：`feat/compact-connection-ui`。

将用户确认的独立 HTML 设计应用到真实插件。演示页面的导航、模拟账号与授权按钮不进入插件；连接状态、账号信息、授权和撤销均沿用 Host RPC。

- 会话授权入口继续位于回复正文末尾，最大宽度 440px。图标、两行文字和操作区垂直居中；状态更新沿用原卡片。
- 设置页展示真实可公开的账号信息和读取范围。重新授权、解除连接收进右上角管理菜单；解除前确认，默认聚焦“保留连接”，Escape 返回管理入口。
- 未连接时只显示一个连接入口。等待授权可取消；浏览器阻止弹窗时提供打开链接；管理员处理类问题可复制申请，复制失败提供可选文本。
- 查询成功与普通查询失败保留行内文本，不新增连接卡片。授权本身不执行查询或自动发送消息。
- 回调结果页采用相同的字体、间距和简洁操作，保持原有 CSP、来源校验和返回会话逻辑。

授权准备页使用 24px 细线旋转图标与一行状态文字，水平与垂直居中；适配深色模式、窄屏和减少动态效果设置。页面不加载外部资源，准备完成后继续原授权跳转。

## 本地验证

浏览器 Harness 使用生产 React 组件、真实 Host RPC 和隔离的合成授权端点，覆盖原位更新、去重、草稿保留、确认弹窗、弹窗拦截、取消重连、刷新、卸载，以及 390px 和桌面布局中的卡片中心线。

这不等同于新的真实企业授权验收；真实钉钉账号、真实业务查询和机器人私聊／群聊仍由人工验收。独立 HTML 保留为设计参考，不作为运行时依赖。

2026-11-03 验证记录：

- 界面主体完整 `pnpm run ci` 通过：上游及边界测试 385 项（334 通过、51 条件跳过），Web 测试 40/40；格式、类型、敏感信息扫描和 tarball 校验通过。
- 48 组状态／中英文／桌面与手机尺寸检查通过，图标、文字和操作共用水平中心线，按钮不横向溢出。
- 原生官方 DSH 安装、设置页和真实 Host 授权入口验证通过；测试在提供方页面前截获跳转，不提交真实企业授权。
- 随后新增加载动效，重新构建并通过组件／Store 定向测试 4/4、完整浏览器 Harness 回归，验证真实准备弹窗的旋转、深色、窄屏、减少动态效果及后续授权跳转。没有将这次增量验证记作第二次完整 CI。
