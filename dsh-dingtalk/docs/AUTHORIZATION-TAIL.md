# 授权卡片移至回复末尾

版本：`0.1.0-phase1.2`。分支：`fix/authorization-reply-tail`。

授权入口使用 DSH 的 `conversation.chat.turnTail` 插槽，显示于回复正文之后、操作栏之前。它从会话工具结果读取授权状态，覆盖嵌套工具调用，不依赖思考区 ToolView 是否挂载，也不解析模型自然语言。

同会话仅最近一次需要授权的回复显示卡片。同轮工具重试沿用原调用标识；授权成功、失效和失败继续更新原卡片。已连接时重放历史记录不新增卡片。原有紧凑布局、设置页授权和成功查询行内反馈不变。

## 验证范围

- 新增尾部选择器测试：嵌套工具结果、同轮重试、跨轮去重、普通失败与无关会话。
- 真实 SlotCore 验证尾部插槽注册及卸载。
- 浏览器 Harness 验证思考区未挂载时仍显示卡片，位置在最终正文之后；展开思考不重复，同一 DOM 卡片原位更新，窄屏不溢出。
- 正式安装包在官方 DSH Web 中加载，设置页经真实 Host RPC 打开授权入口并取消；浏览器在钉钉页面跳转前截获，不提交真实授权。
- 完整 CI 首轮发现旧 CLI 子进程测试偶发失败，单独重跑又遇到启动就绪等待超时。Windows 测试夹具增加启动余量，仍断言超时／取消结果和父子进程均终止；正式执行限额不变。

浏览器和原生安装报告见 `docs/evidence/authorization-tail/`。报告分别标注验证边界：尚未在原生会话中回放真实模型工具调用；真实企业授权、真实 LLM 对话及机器人私聊／群聊仍需人工验收。

2026-11-02 本地结果：上游及边界测试 385 项，334 通过、51 按条件跳过、0 失败；调整夹具后完整 Web 测试 40/40 通过；类型检查、敏感信息扫描、格式检查和 tarball 检查通过。完整 CI 首轮未全绿，失败段修正后单独复跑 Web 测试与打包检查通过，没有将单独复跑描述为整条 CI 再次执行。
