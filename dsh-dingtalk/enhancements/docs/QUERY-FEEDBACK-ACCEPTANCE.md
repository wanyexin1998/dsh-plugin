# dev.6 查询结果与授权提示修复

真实联调的脱敏工具结果确认：文档查询出现 invalid_cli_output 和 queue_timeout，同时本人信息及日历有成功结果，不能据此认定用户未授权。没有保存会话正文、搜索词、文档、账号 ID 或凭据。

根因与处理：

- 官方 DWS doc search 的合法成功 JSON 可以把 documents / hasMore / nextPageToken 放在顶层。新增仅限 docs.search 的结构适配；中文、无关键词和空结果均处理。非法结构继续拒绝，不通过截取日志或放宽任意 JSON 解析绕过校验。
- 查询解码/排队错误不清除已有在线身份验证；真实账号经新版适配器执行一次原查询，返回 ok，连接仍为 connected。真实结果内容不进入证据。
- 仅 auth_required / 明确过期进入授权反馈，且须由 Host 状态确认。已连接后刷新历史授权结果不会生成卡片；同一会话多个授权需求共享一张原卡片。
- 普通失败用行内提示，成功仅一行「钉钉 · 查询完成」，不展示自定义结果卡片或原始 JSON。模型仍接收 Tool 数据并正常回答。
- 焦点/订阅/轮询的重复状态请求合并；Tool 与 Skill 限制无效重试，禁止把业务失败误说成未授权或中文编码错误。

回归覆盖：顶层文档结构、空结果、非法结构不撤销身份、单会话提示去重、并发刷新合并、已连接历史结果静默、成功/失败行内展示、浏览器完整授权到原卡片更新。报告在 docs/evidence/query-feedback。测试夹具与真实只读验证分别标记，不代表企业失败账号、全部权限、LLM 或 Desktop 验收已完成。
