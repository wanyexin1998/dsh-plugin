# OAuth 回调兼容修复：dev.5

真实联调发现钉钉可在同一次回调中同时返回 code 和 authCode，且两者相同。dev.4 将它误判为重复授权码，返回 HTTP 400，尚未执行换码。本次不保存、重放或记录真实授权码。

dev.5 允许两个别名各出现一次且值相同，只执行一次换码；不同值、同名字段重复、空值、error 与 code 共存、重放仍拒绝。state、浏览器 cookie、有效期和在线身份校验保持不变。

OAuth 定向回归 5 项通过，类型检查通过；合成 Provider 同时返回两个别名，浏览器集成覆盖原卡片回填。打包与安装证据记录在 docs/evidence/callback-aliases。更新实例后必须重新点击连接发起新事务，旧回调不能复用。真实企业完整授权仍需用户重试后确认。
