获取当前登录用户的 userId 与基本信息。

触发词：我是谁 / 我的信息 / 我的 userId / 当前用户 / 本人 / self / me / whoami / current。
别名：self / me / whoami / current 均等价于 get-self。
无需参数；禁止用 `dws contact user get --ids me/self` 代替（会返回空数据的假成功）。

Usage:
  dws contact user get-self [flags]

Aliases:
  get-self, self, me, whoami, current

Examples:
  dws contact user get-self
  dws contact user self       # 别名（等价）
  dws contact user me         # 别名（等价）

Flags:
  -h, --help   help for get-self

Global Flags:
      --client-id string       覆盖 OAuth 客户端 ID (钉钉 AppKey)
      --client-secret string   覆盖 OAuth 客户端密钥 (钉钉 AppSecret)
      --debug                  显示调试日志
      --dry-run                预览操作内容，不实际执行
      --fields string          筛选输出字段 (逗号分隔, 如: name,id,status)
  -f, --format string          输出格式: json|table|raw|pretty|ndjson|csv (default "json")
      --jq string              jq 表达式过滤输出 (如: '.items[] | .name')
      --mock                   使用 Mock 数据 (开发调试用)
      --profile string         一次性指定组织或账号；支持 corpId/corpName 与 userId/userName 组合，推荐使用 profile list 返回的 corpId:userId；多个按 CSV 逗号分隔
      --timeout int            HTTP 请求超时时间 (秒) (default 30)
  -v, --verbose                显示详细日志
  -y, --yes                    跳过确认提示 (AI Agent 模式)

When to use:
  - 用户问我是谁/我的 userId/当前账号信息

Avoid when:
  - 查他人详情用 contact user get 或先搜索

Safety: effect=read  risk=low  confirmation=not_required  idempotency=idempotent
