## rc.2 适配踩坑（务必记住）
1. 宿主模块同时导出 Service 类与 `apply` 时，Loader 会**静默挂载类**，`apply` 不执行，Remote 端点不被认领（404 且无任何告警）。→ API 行只导出函数式插件，服务类拆到 `api-service.ts`。
2. SRC 模式 Remote 方法按**形参名**取参，不能用单一 `args` 对象参数。
3. Remote 线格式：`POST /api/<ns>/<method>`，body `{type:'client-request',rpcId,method,payload:{args:{…}}}`。
4. 会话种子事件必须带 `seq`/`time` 完整信封。
5. 收件箱是持久投影（`agent/inbox/spliced`），跨重启保留待执行命令 → 恢复门禁必须先装备。
6. TypertGateway 的 SRC 端点认领表**只计算一次**（`collectSrcClaims` 缓存）。
