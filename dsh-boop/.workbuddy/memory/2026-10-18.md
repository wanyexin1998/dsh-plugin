## 2. rc.2.1 对齐关键发现（务必记住）
1. **插件兼容门（最重要）**：`@deepseek-ai/dsh-app-boot` 新增 `evaluatePluginCompatibility`。
   - 若清单声明 `engines.dsh`，它**单独决定**，peerDependencies 被忽略；
   - 否则逐个校验 `@deepseek-ai/dsh` 与 `@deepseek-ai/dsh-*` 的 peer 范围（prerelease 参与）；
   - 不满足时 bundle 被**静默跳过**（stderr 只有 `dsh: skipping profile bundle "dsh-boop": Error: Plugin dsh-boop@0.1.0 is incompatible…`），
     表现是 BOOP 行完全不装配、`/api/boop/*` 404、客户端模块图里没有 dsh-boop。
   - 处理：BOOP `package.json` 增加 `engines.dsh = "0.2.1-rc.2"`，peers 全部升到 0.2.1-rc.2。
   - 另：profile 级 `compatibility.json` 可写精确豁免 `name@version -> [runtimeVersion]`；
     **BOOP 不申请豁免**（对齐而不是绕过风险）。
