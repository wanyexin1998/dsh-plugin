# BOOP（波波）开发交接包

> 交付编号：**v1.2-FROZEN-R1** · 冻结日期：2026-10-17  
> 产品与视觉基线：用户已确认的 **BOOP Design Pack v1.2**。本包只补充工程交接，不重画视觉、不变更已确认产品范围。

## 立即开始

1. 打开 **`BOOP_开发交接阅读器.html`**：先读“冻结与开工”，再按岗位阅读六册正文和交接附录。
2. 技术负责人按 **`handoff/01_开发路线与任务清单.md`** 建立 Issue；`handoff/issues/` 已提供逐项可复制的任务正文。
3. **先做 M0 基线验证，再启用业务写操作。** 模型、消息来源、恢复门禁、数据域与鉴权验证未通过时，只可在隔离测试域开发验证，不在真实项目开启代理派发。

## 不要误读交付状态

**已冻结的是设计，不是已验证的插件。** 本包没有可安装插件、模型密钥、渠道凭证或真实项目执行结果。G01—G09、TB01—TB10、FE-01—FE-12、AT-01—AT-40 的工程执行状态均初始化为 `NOT_RUN`。

现有 SQL／TS／配置是实现起点，不是可直接上线代码。透明角色、独立 SVG、微尺寸头像等生产资产仍需按已确认形象制作，已纳入设计交接任务。

## 完整性检查

在解压目录运行（需要 Python 3.9+；不联网、不安装依赖）：

```bash
python tools/verify_package.py
```

Windows 也可使用 `py -3 tools/verify_package.py`。这只校验交付文件，不执行项目代码或迁移。产品运行验收另按验证门进行。

**负责人填写、排期估算、仓库创建和发布均由开发团队执行。本包没有替团队建立 GitHub Issue，也没有授权生产变更。**
